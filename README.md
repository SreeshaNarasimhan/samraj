# Samraj Pre School

Official website for Samraj Pre School, a play-based preschool located in Jalakandapuram, Salem.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Type Checking**: TypeScript
- **Bundler**: Vite

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
npm install
```

### Development

Start the development server:

```sh
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To build for production:

```sh
npm run build
```

To preview the production build locally:

```sh
npm run preview
```
